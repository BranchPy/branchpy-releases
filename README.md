# BranchPy

**Understand your project before it breaks.**

BranchPy is a local-first project analysis tool for **Ren'Py** and **Godot** creators.

Analyze branching logic, validate assets, uncover structural risks, and visualize project flow from a single workspace. Whether you're building a visual novel, narrative RPG, simulator, or complex game system, BranchPy helps you understand how your project is actually connected.

---

## Why BranchPy?

As projects grow, they become harder to reason about.

Questions start appearing:

- Which branches are unreachable?
- Where do players hit dead ends?
- Which assets are missing or never used?
- What changed between two analysis runs?
- Which parts of the project have become difficult to maintain?

BranchPy turns your project into a navigable map and surfaces issues before they become production problems.

---

## Built for Ren'Py

BranchPy helps visual novel creators:

- Visualize complete story flow
- Detect unreachable labels
- Find dead-end narrative paths
- Analyze branching complexity
- Validate media references
- Track project evolution over time

Perfect for hobby projects, game jams, and commercial productions alike.

---

## Built for Godot

BranchPy also analyzes Godot projects, helping developers:

- Understand project structure
- Review dependencies and relationships
- Detect missing or inconsistent assets
- Identify maintainability risks
- Compare project changes between analysis runs

Useful for narrative games, RPGs, adventure games, simulation projects, and larger productions where understanding project complexity becomes increasingly important.

---

## Key Features

### Project Analysis

Find structural issues before they become bugs.

- Broken or unreachable paths
- Logic inconsistencies
- Structural dependencies
- High-risk areas of the project
- Complexity indicators

### Visual Flow Mapping

Explore your project through interactive visualizations.

- Branching flowcharts
- Relationship mapping
- Navigation through project structure
- Rapid identification of bottlenecks

### Asset Validation

Keep your project clean and consistent.

- Missing assets
- Unused assets
- Invalid references
- Project-to-file mismatches

### Comparative Reports

Compare saved analysis runs and quickly see what changed between milestones, releases, or commits.

---

## Local-First by Design

Your project stays under your control.

- Read-only by default
- Source files are never modified automatically
- Deterministic analysis
- Core processing runs locally
- Optional AI features remain disabled until explicitly enabled

BranchPy is designed to help you understand your project, not take control of it.

## Getting Started

1. Install BranchPy Studio.
2. Create a BranchPy account.
3. Connect BranchPy Studio.
4. Open your Ren'Py or Godot project.
5. Run analysis and review the results.
